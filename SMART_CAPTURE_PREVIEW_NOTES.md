# My Wine Cellar v3.2.1 Preview 1 — Smart Capture

## Purpose
This preview prioritises functionality over design.

## New workflow
1. Tap Add wine.
2. Tap **Scan barcode**.
3. The app checks the local cellar first.
4. If already known, add one bottle, create a new record from the known wine, or edit the existing record.
5. If unknown locally, the app searches Open Food Facts.
6. Review any suggested details before using them.
7. Confirm the vintage, location and quantity and Save.

## Confidence
- High: exact barcode matched a record already stored locally.
- Medium/Low: external metadata suggestion. Always verify it.

## Deliberately not included yet
- AI label recognition
- Drinking-window intelligence
- Cloud/shared catalogue
- Design polish
